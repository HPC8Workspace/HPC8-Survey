นำเข้าข้อมูลแบบประเมิน

อัปโหลดผลจาก Canva Sheets หรือวางตารางที่คัดลอกมา

รองรับ Excel (.xlsx), CSV UTF-8, TSV, Markdown และ JSON · ใช้หัวคอลัมน์ เช่น response_id, m1, n1, e1
เลือกชีท
รูปแบบข้อมูลและการเก็บงาน

ใช้ชื่อคอลัมน์จาก Canva เดิม ระบบรองรับ p01–p13 ตามคอลัมน์ที่พบ คะแนน 1–5 เท่านั้น FALSE และช่องว่างไม่ถูกนับเป็นคะแนน 0 นำเข้าแต่ละครั้งเป็นการแทนชุดข้อมูลเดิม ดาวน์โหลด JSON เพื่อเก็บงานและนำเข้าต่อได้ รวมตัวเลือกตัดแถวและชื่อคำถามที่แก้ไข

วิธีใช้งานและเก็บงาน

1. เปิดเว็บไซต์ด้วย Chrome หรือ Edge โดยเชื่อมต่ออินเทอร์เน็ตเพื่อเข้าใช้งานผ่าน GitHub Pages

2. เลือกไฟล์ Excel (.xlsx), CSV UTF-8, TSV, Markdown หรือ JSON หรือกดวางข้อมูล

3. ตรวจคุณภาพข้อมูล เลือกตัดแถวทดสอบ และตรวจชื่อคำถาม/สินค้าให้ตรงกับแบบจริง

4. เปิดรายงานพร้อมใช้เพื่อดาวน์โหลดรายงาน HTML ตาราง CSV หรือพิมพ์และเลือกบันทึก PDF

5. ก่อนปิดหน้า ให้กดเก็บงาน JSON จากหน้ารายงาน พร้อมใช้ไฟล์ JSON นั้นนำเข้าครั้งถัดไปเพื่อกู้ข้อมูล ตัวเลือกตัดแถว และชื่อหัวข้อที่แก้ไข

ไฟล์นี้ไม่บันทึกข้อมูลอัตโนมัติ และไม่ดึงข้อมูลจาก Canva Sheets โดยตรง กรุณาส่งออกข้อมูลจาก Canva แล้วนำเข้าใหม่เมื่อมีคำตอบเพิ่ม
